# 🎓 Site Acadêmico

> Projeto de desenvolvimento web acadêmico, desenvolvido com foco na construção de uma interface moderna, organização visual e aplicação de tecnologias atuais de desenvolvimento Front-end.

## 📌 Sobre o projeto

O **Site Acadêmico** é um projeto desenvolvido com o objetivo de explorar conceitos de desenvolvimento web, criação de interfaces e organização de aplicações utilizando tecnologias modernas.

A proposta é construir uma experiência digital organizada, intuitiva e responsiva, aplicando boas práticas de programação e estruturação de componentes.

## 🚀 Tecnologias utilizadas

As principais tecnologias e ferramentas utilizadas no projeto são:

- **React 19** – Construção de interfaces e componentes.
- **TypeScript** – Tipagem estática e organização do código.
- **Vite** – Ambiente de desenvolvimento e compilação.
- **Material UI (MUI)** – Componentes visuais e elementos de interface.
- **Tailwind CSS** – Estilização e organização do layout.
- **HTML5** – Estruturação das páginas.
- **CSS3** – Estilização e apresentação visual.
- **Git e GitHub** – Versionamento e armazenamento do código.

## 🛠️ Como executar o projeto

### Pré-requisitos

- Node.js instalado.
- Git instalado.
- Gerenciador de pacotes pnpm.

### Instalação

1. Clone o repositório:

```bash
git clone https://github.com/Juan-Pablo18/Site-Academico.git
```

2. Entre na pasta do projeto:

```bash
cd Site-Academico
```

3. Instale as dependências:

```bash
pnpm install
```

4. Inicie o ambiente de desenvolvimento:

```bash
pnpm dev
```

5. Acesse o endereço disponibilizado pelo Vite no terminal.
